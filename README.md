# modular-hr

**채용부터 퇴사까지(Hire-to-Retire)** 사업장의 인사노무·급여 계산 규칙을 근로기준법에 따라 검증하고, **사업장 규모(상시근로자 수)와 업종(KSIC)**에 따라 필요한 법정 제도·문서 초안·신고 기한·분기별 운영 일정을 자동으로 구성해 주는 모듈형 플랫폼의 **Phase 1 로컬 시뮬레이터 & 규칙 엔진 프로토타입**입니다.

## 현재 프로토타입 구현 범위 vs 차기 확장 범위

| 구분 | 현재 저장소에 실제 구현된 범위 (Phase 1 프로토타입) | 차기 단계 구현 예정 범위 (Phase 2~3) |
|---|---|---|
| **저장소·보안** | 인메모리(In-Memory) 상태 스토어, `127.0.0.1` 로컬 바인딩, `Host`·`Origin`·CSRF·CSP·엄격 입력 타입 검증 | PostgreSQL 멀티테넌트 RLS 분리 저장소, KMS 기반 주민번호·계좌 암호화 금고(`vault.pii_secrets`) 영구 저장 |
| **규모·업종 프로비저닝** | 근기법·산안법·장애인법 상시근로자 수 실시간 산정, 4계층 모듈 활성 판정, 법정기한(14일·15일·연간 기한) D-Day 계산, 분기 일정표 산출 | 일별 배치 스케줄러, 담당자·사업주·노무사 이메일/알림톡 에스컬레이션 발송 |
| **법정 문서·절차** | 노사협의회 규정·신고서, 분기별 회의록 양식, 안전·보건관리자 선임보고서, 취업규칙 신고서, 표준 근로계약서 **작성 보조 초안** 생성 | 실제 근로자 모바일 비밀투표 집계, 전자서명·교부 증빙 보관, 노동포털·4대보험 EDI 연계 |
| **생애주기·급여** | 채용절차법 금지어·최저임금 검증, 5인 이상/미만 가산수당, 주 52시간 경보, 제95조 감봉 한도 캡핑, 퇴직금(평균 vs 통상임금)·지원금 감원방지 경보 | 은행 급여이체 전문 생성, 홈택스 간이지급명세서 전자신고 파일 출력, 취업규칙 OCR 파서 |
| **멀티문서 자동 온보딩 & 퇴사자 원장** | 사업자등록증·회사 홍보자료·건강/고용보험 내역 일괄 파싱(주민번호·전화번호 즉시 마스킹), 업종(KSIC) 자동 분류, 대표자 제외 상시근로자 역산, 건보↔고보 보수·자격 괴리 대사, 상실자 **퇴사자 통합 원장(14일 청산·상실신고·제39조 사용증명서·제42조 3년 보존 가드레일·만료 파기·모바일 차단)** 자동 연결 | 스캔 PDF/이미지 외부 Vision OCR 엔진 어댑터 연동 및 공단 EDI 자동 송수신 |
| **대표·관리자 모바일 앱** | PWA 모바일 앱(`/mobile.html`), 비동기 `scrypt` 로그인 + 분리형 2차 인증(6자리 보안 PIN / ECDSA P-256 공개키 전자서명 패스키) + 5회 실패 잠금, 역할별 RBAC(`CEO`·`HR_ADMIN`·`DEPT_MANAGER`·`WORKER`), 2단계 결재(`PENDING_DEPT` -> `PENDING_CEO` -> `APPROVED`)·급여 잠금(`APPROVED_LOCKED`) 보호, 기기 세션 원격 강제 해제, 퇴사자 사후관리 실시간 체크, SSE 실시간 푸시 | Capacitor 기반 iOS/Android 스토어 앱 패키징, 실제 FIDO2 하드웨어 인증기 바인딩 및 FCM/APNs 네이티브 푸시 연동 |

## 실행 및 테스트 방법

외부 패키지 의존성 없이 Node.js(20 이상) 표준 내장 모듈만으로 동작합니다.

```bash
# 전체 파일 문법 검사 (PowerShell에서는 npm.cmd 사용 가능)
npm.cmd run check

# 도메인 규칙 · 경계값 · 모바일 RBAC/MFA/SSE · 보안 통합 테스트 실행
node --test test/engine-and-server.test.mjs

# 로컬 시뮬레이터 & 모바일 앱 웹 서버 실행
# - 기본 보안 모드: 초기 자격증명은 평문 로그로 출력되지 않으며 MHR_INIT_CREDENTIALS_JSON 환경변수(8자 이상 password, 6자리 숫자 pin 엄격 검증)로 주입합니다.
# - 로컬 UI 체험 시: MHR_DEMO_MODE=1 지정 시 난수 생성된 데모 계정의 1클릭 체험 입력을 지원합니다(보안상 MHR_INIT_CREDENTIALS_JSON과 동시 사용은 기동 거부됨).
# - 로그인 보호 정책: (IP, 아이디) 버킷 레이트 리미트 및 5회 연속 인증 실패 시 5분간 계정 잠금(미등록 아이디도 동일 429 응답)이 적용됩니다.
#   (로컬 공유 환경에서는 의도적 5회 오입력으로 5분 일시 잠금이 발생할 수 있으며, 운영 배포 시 리버스 프록시/WAF 캡차·신뢰 기기 예외와 결합을 권장합니다.)
# - PC 대시보드(/api/*)도 기본적으로 CEO 또는 HR_ADMIN 2차 인증 완료 쿠키 및 세션 바인딩 CSRF 토큰이 필수입니다.
#   (단일 사용자 격리 개발 환경에서 MHR_ALLOW_UNAUTH_PC=1 지정 시 같은 PC의 모든 로컬 프로세스가 시뮬레이터 API에 접근 가능하므로 개발 테스트 외에는 사용 금지)
# - 대표·관리자·근로자 모바일 앱: http://127.0.0.1:4310/mobile.html
# - PC 통합 대시보드: http://127.0.0.1:4310/
node src/server.mjs
```

## 보안 원칙

- 실제 주민등록번호·휴대전화번호·계좌번호·이메일 등 실명 개인정보를 저장소에 포함하지 않습니다.
- 로컬 서버는 `127.0.0.1`에만 바인딩되며 `Host` 허용 목록, `Origin`/`Sec-Fetch-Site`, 타이밍 안전 CSRF 토큰, 엄격한 타입 검증, 텍스트 기반 DOM 렌더링(`innerHTML` 미사용)을 적용합니다.
- 상세 PostgreSQL 물리 스키마 설계 및 노동법 계산 규칙 명세는 `docs/DB_AND_RULES_SPEC.md`를 참고하세요.
